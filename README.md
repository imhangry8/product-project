# Product Intern Project

产品实习相关的 AI 技能资料，包含产品工作流程、用户研究、用户画像、竞品分析、需求文档、功能优先级、用户旅程和指标验证。

## 内容

- `product-intern-agent/`：产品实习工作流程
- `user-research/`：用户研究
- `user-personas/`：用户画像
- `competitor-analysis/`：竞品分析
- `create-prd/`：需求文档
- `prioritize-features/`：功能优先级
- `customer-journey-map/`：用户旅程
- `validate-metrics/`：验证相关资料

每个目录保留原有技能文件；可用的代理配置和图标已从内层 ZIP 中提取。

## 版本说明

原始压缩包中的部分目录与内层 ZIP 包含不同版本的 `SKILL.md`。根目录下保留外层文件夹版本，差异版本保存在 `archive-versions/`，内层原始 ZIP 保存在 `original-archives/`。原始备份内容均保留，已清除 macOS 系统元数据。
